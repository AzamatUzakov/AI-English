# План реализации — English AI Tutor (Интеграция логики)

Этот план описывает процесс разделения разработки веб-платформы **English AI Tutor** на конкретные пошаговые подзадачи. Главный приоритет — **полная сохранность существующего визуального дизайна**, стилей, Tailwind-токенов, палитры цветов и HeroUI-компонентов. Изменения затрагивают исключительно логику, роутинг, управление состоянием (React State) и сетевое взаимодействие с API.

## Пошаговое разделение на подзадачи (5 фаз)

### Фаза 1: Инициализация Базы Данных и Бэкенда
* **Подзадача 1.1: Накатывание миграций Prisma**
  * Запустить `npx prisma db push` для развертывания таблиц `lessons`, `lesson_messages` и `diary_rules` на локальной БД PostgreSQL (`mam_db`).
* **Подзадача 1.2: Проверка БД через Prisma Studio**
  * Запустить `npx prisma studio` и убедиться, что все сущности готовы к записи данных.
* **Подзадача 1.3: Запуск бэкенд-сервера**
  * Запустить `npm run start:dev` в каталоге `backend` и убедиться в успешном старте на порту `3000` с включенным CORS.

---

### Фаза 2: Сетевой API-клиент и Инфраструктура Роутинга
* **Подзадача 2.1: Создание API-клиента (`shared/api.ts`)**
  * Реализовать легкий HTTP-клиент на базе `fetch` для интеграции с NestJS бэкендом (`http://localhost:3000`).
  * Реализовать методы:
    * **Lessons**: `createLesson(topic?: string)`, `getLessons()`, `getLessonById(id: string)`, `generateLessonSummary(id: string)`
    * **Messages**: `getLessonMessages(lessonId: string)`, `sendMessage(lessonId: string, role: string, content: string)`
    * **Diary**: `getDiaryRules()`, `saveDiaryRule(lessonId: string, topic: string, title: string, content: any)`, `deleteDiaryRule(id: string)`
* **Подзадача 2.2: Внедрение React Router в `App.tsx`**
  * Обернуть приложение в `BrowserRouter`.
  * Задать маршруты, сохраняя общую компоновку:
    * `/` — `DashboardPage` (Дашборд)
    * `/lesson/:id` — `LessonPage` (Интерактивный чат урока)
    * `/lesson/:id/result` — `ResultPage` (Итоги урока)
    * `/diary` — `DiaryPage` (Дневник)

---

### Фаза 3: Разработка страниц на Фронтенде (Бизнес-логика)
* **Подзадача 3.1: Страница Дашборда (`DashboardPage.tsx`)**
  * Получить список всех прошлых уроков через `getLessons()`.
  * Реализовать подсчет статистики: средний балл (average score), текущая серия дней занятий (streak) на основе дат уроков.
  * При нажатии на кнопку "Начать новый урок" делать запрос `createLesson()` и перенаправлять пользователя на `/lesson/:id`.
* **Подзадача 3.2: Страница Результатов (`ResultPage.tsx`)**
  * Загрузить данные урока по ID при помощи `getLessonById(id)`.
  * Вывести радиальный прогресс оценки (`score`), сильные и слабые стороны (`strong`, `weak`), саммари от ИИ (`summary`).
  * Вывести рекомендацию следующей темы (`nextRec`) с кнопкой "Начать следующий урок", которая создает новый урок с этой темой.
* **Подзадача 3.3: Страница Дневника (`DiaryPage.tsx`)**
  * Загрузить правила через `getDiaryRules()`.
  * Добавить интерактивный поиск по названию правила и фильтрацию по темам (тегам).
  * Реализовать удаление карточки через `deleteDiaryRule(id)` с мгновенным обновлением списка.

---

### Фаза 4: Реализация Чат-Страницы (Интерактивный урок и таймер)
* **Подзадача 4.1: Интеграция сообщений в `Chat.tsx`**
  * При загрузке страницы `/lesson/:id` получать историю чата через `getLessonById(id)` и загружать все сообщения.
  * Реализовать отправку сообщений через `sendMessage()`. При вводе сообщения блокировать инпут и выводить статус "ИИ печатает...". При получении ответа разблокировать инпут.
* **Подзадача 4.2: Динамический таймер обратного отсчета**
  * Реализовать таймер (например, на 60 минут) с использованием хуков React.
  * При времени менее 5 минут добавлять CSS-класс `text-error animate-pulse` (пульсирующий красный) для секции таймера.
* **Подзадача 4.3: Логика завершения урока**
  * Когда таймер достигает `00:00`, заблокировать текстовое поле.
  * Показать полноэкранный лоудер: "Урок завершен! Подводим итоги...".
  * Вызвать метод `generateLessonSummary(id)`, сохранить результат и выполнить редирект на `/lesson/:id/result`.

---

### Фаза 5: Парсер Интерактивных Правил ИИ (`rule_card`)
* **Подзадача 5.1: Выделение JSON из сообщений в `Message.tsx`**
  * Добавить парсер в компонент `Message`, который находит блоки кода с JSON-карточками формата `rule_card`.
* **Подзадача 5.2: Рендеринг таблицы правила**
  * Если в сообщении найдена `rule_card`, отрендерить красивую таблицу на основе `content.headers` и `content.rows`.
* **Подзадача 5.3: Интерактивная кнопка "+ Сохранить в дневник"**
  * Добавить кнопку к таблице, вызывающую `saveDiaryRule()`.
  * При успешном сохранении обновлять боковую панель `DiaryPanel` и воспроизводить анимацию добавления.
